What it is

A managed workspace, not a bigger prompt.

It organizes an agent's accessible working representations into a deliberately managed workspace: a single entry point, nine selectively-loaded modules, three supporting references, and an optional standard-library controller for durable task state. It operates at inference time only — model weights and training remain unchanged.

“Dense on the inside, decodable on demand, clean on the outside. Use only the machinery the task earns.”

How it works

The entry gate picks the lightest pass that holds.

A request for brevity changes outer response length; verification stays aligned to the task's floor. Short work stays light — long work gets durable state only when it needs it.

fast

Suitable work: one step, or a result checkable in one glance.

loads → nothing extra
full

Suitable work: several dependent steps, one bounded deliverable.

loads → one or two modules, ship before delivery
loop

Suitable work: multiple stages, files, turns, tools, or persistent state.

loads → ledger, seams, checkpoints, register audit, recovery

Install & usage

Copy the runtime directory, verify, reload.

Download or clone the repository.

Locate the user-level Skills directory used by your AI host.

Copy the complete j-space/ directory into it, so the installed entry is <skills-directory>/j-space/SKILL.md.

Run the integrity check with an available Python 3 interpreter: <python-command> <skills-directory>/j-space/scripts/verify_suite.py.

Reload the host if it discovers Skills at startup. The directory must stay intact — SKILL.md routes to relative paths under modules/, references/, and scripts/.

# maintainer verification, from the repo root
python3 j-space/scripts/verify_suite.py
python3 -m unittest discover -s tests -v
/j-space$j-spacedirect natural-language request

The entry gate selects the lightest suitable pass (fast / full / loop) automatically for whichever invocation form the host supports.
