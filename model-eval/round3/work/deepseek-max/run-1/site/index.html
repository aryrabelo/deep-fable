J-Space Cognition Suite V3.6

A model-agnostic, inference-time control system for deep reasoning, long-horizon work, tool use, verification, and recovery. It operates entirely at inference time — model weights and training remain unchanged.

"Dense on the inside, decodable on demand, clean on the outside." Use only the machinery the task earns.

How it works

Three passes, loaded only when the task earns them

A single entry gate auto-selects the lightest pass suitable for the request. A request for brevity shortens the outer response — it does not lower verification below the task's floor.

Pass · fast

One step, checkable in a glance

Nothing extra loads. The entry gate keeps overhead at zero for trivial requests.

Pass · full

Several dependent steps, one bounded deliverable

One or two relevant modules load; the ship check runs before delivery.

Pass · loop

Multiple stages, files, turns, tools, or persistent state

Ledger, seams, checkpoints, register audit, and recovery all become active.

Seven core mechanisms

Selective workspace loading

Keeps one or two load-bearing ideas active and externalizes the rest.

Broadcast hub

Gives dependent branches one shared source for names, values, constraints, and style anchors.

Dense Track

Carries long internal chains in compact, decodable notation before returning to clean outer language.

Bridge-before-conclusion reasoning

Makes required intermediates explicit before a conclusion consumes them.

Metacognitive control

Routes confidence, inconsistency, and failure signals into a concrete next action.

Empirical escape & verification

Converts stalled derivation into bounded tests with a named verifier and coverage.

First-person agency & functional echo

Uses "I", "we", "let's", "we need" to bind workspace state to later actions and checks.

Optional controller — jspace.py

Externalizes loop-pass state into a .jspace/ directory inside the current task workspace, using the Python standard library only. The controller records and reports state — solution choice remains with the model.

Install & usage

Manual install (Option A)

  1. Get the repo

    Download or clone J-Space-Cognition-Suite-V3.6.

  2. Locate the Skills directory

    Find the user-level Skills directory used by your AI host.

  3. Copy j-space/ in

    So the installed entry is <skills-directory>/j-space/SKILL.md. The directory must stay intact — SKILL.md routes to relative paths under modules/, references/, and scripts/.

  4. Run the integrity check

    With any available Python 3 interpreter (python, python3, or py -3).

  5. Reload the host

    If it discovers Skills at startup. Keep LICENSE and THIRD_PARTY_NOTICES.md with any redistribution.

# integrity check
<python-command> <skills-directory>/j-space/scripts/verify_suite.py

# maintainer verification, from repo root
<python-command> j-space/scripts/verify_suite.py
<python-command> -m unittest discover -s tests -v

Invoke it

Through the mechanism your host provides — its Skill picker, /j-space, $j-space, or a direct request. The entry gate selects the lightest suitable pass automatically.

J-Space Cognition Suite

Uses the operational workspace terminology from Anthropic's related interpretability research; first-person language is treated as control grammar bound to explicit actions, checks, and settles. Reproduced effects reported across DeepSeek, Qwen, GLM, GPT, and Claude model families, with effect size varying by base capability, context policy, tool harness, and benchmark implementation.
